# Amazon Login Page Automation Framework | Selenium with Java

## 📌 About This Project

This project is a Selenium Automation Testing Framework designed and developed from scratch using Java, Selenium WebDriver, TestNG, and Maven.

The framework is developed to automate the Amazon website Login Page using a structured, modular, and reusable architecture.

It follows the Page Object Model (POM) design pattern and includes reusable base classes, custom TestNG listeners, test data readers, utility methods, reporting, Docker configuration, and Jenkins integration.

The main objective of this project is to understand framework development from scratch and implement a maintainable and scalable automation testing solution.

**Website:** [Amazon India](https://www.amazon.in/)

**Module:** Login Page

**Testing Type:** Web UI Automation Testing

## 🎯 Project Objectives

- Design and develop an automation framework from scratch.
- Automate Amazon Login Page test scenarios.
- Implement Page Object Model (POM).
- Create reusable base classes and utility methods.
- Implement custom TestNG listeners.
- Manage test data using external data readers.
- Generate automation execution reports.
- Explore Docker integration for test execution.
- Integrate automation testing with Jenkins CI/CD.
